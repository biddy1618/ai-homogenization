# One-pager for the Homogenization Tracker — implementation handoff

Three finished design directions for a printable one-page summary of the tracker. The client picks one; build that one. Everything below applies to all three unless a section names a draft.

| Draft | File | Idea |
|---|---|---|
| A — The Axis Is the Argument | `static/A-AxisIsTheArgument.html` | The client's sketch: a 0–1 trend chart whose y-axis is anchored by five distinct historical figures (bottom) and identical figures (top). |
| B — Two of Five | `static/B-TwoOfFive.html` | Hero number 1.98 distinct pages out of 5; five page thumbnails, three shown as duplicates, each topped by a portrait or an identical figure. |
| C — Ninety-Six Questions | `static/C-QuestionGrid.html` | One square per question, coloured by similarity; the figures form the colour key. |

Open the `static/` files in a browser to see the intended result; `previews/` has PNG renders of each.

## 1. What to build

- A static page at `tracker/onepager/index.html`, generated by the same weekly job that builds `tracker/dashboard/` (extend `tracker/dashboard/build.py` or add `tracker/onepager/build.py`).
- Design size 1000 × 1414 px (A4 portrait ratio). Must print to one A4 page: `@page { size: A4; margin: 0 }`, `print-color-adjust: exact`.
- On screens narrower than 1000 px, scale the whole page down proportionally (CSS `transform: scale()` or `zoom`); do not reflow it.
- **No hard-coded numbers.** Every figure on the page is recomputed from the CSVs on each build (section 4). The `static/` files contain today's values only as a reference.
- Self-contained: inline the SVG illustrations and the QR code. Google Fonts is the only external request.

## 3. Shared structure (all drafts)

1. **Masthead:** five ramp dots + "HOMOGENIZATION TRACKER"; right side "Weekly · Run {n} · Updated {latest run date}".
2. **Eyebrow + H1 + one-sentence deck.** Copy is in each draft; keep it verbatim unless the client edits it.
3. **The visual** (differs per draft, section 5).
4. **Footer:** panel note (one paragraph), links "Full dashboard →" (`../dashboard/`) and "Methodology and data →" (repo), and a QR code to the dashboard on a light tile (`#F2F3F5`) so it scans when printed.

## 4. Data mapping

Sources: `tracker/data/runs_top5.csv`, `tracker/data/_runs_meta.csv`, `tracker/queries.txt`.
"Latest run" = max `date`. "Core 45" = first 9 queries per category in `queries.txt`.
Reference implementation of every calculation: `scripts/compute_stats.py` and `scripts/latest_per_question.py`.

| Element | Computation | Value on 2 Nov 2026 |
|---|---|---|
| Trend line | Per date: mean `mean_pairwise_cosine` over **core-45 rows only**, so the series stays comparable across the 45→100 panel change | 0.7017, 0.7316, 0.7433, 0.7879, 0.7863, 0.7836 |
| Provider-change marker | Dashed vertical line midway between the two runs where `engine` changes in `_runs_meta.csv`. **Never remove it:** the largest step in the line sits on it | between 12 and 19 Oct |
| Distinct pages (hero in B) | Mean `vendi`, latest run, all questions, 2 decimals | 1.98 |
| "of questions above 0.80" | Share of latest-run rows with `mean_pairwise_cosine` > 0.80. Draft C's headline says "Half" only while this is 45–55%; otherwise use the number | 50% |
| "fewer than 2 distinct pages" | Share of latest-run rows with `vendi` < 2.0 | 59% |
| Most uniform / most varied | Arg-max / arg-min of `mean_pairwise_cosine`, latest run; `query` text verbatim, value to 3 decimals | "is intermittent fasting healthy" 0.905 / "what causes lower back pain" 0.174 |
| Most / least uniform domain | Mean similarity per `category`, latest run | science / law |
| Question grid (C) | One cell per latest-run row, one row per category (alphabetical), cells sorted high→low, coloured by the ramp; outline the max and min cells; row-end number = category mean | 96 cells |
| Panel footnote | Panel size from `queries.txt`; readable count = latest-run rows; panel-change and provider-change dates from `_runs_meta.csv` | 100 / 96 |
| Masthead run number and date | Count of distinct `date` values; latest date formatted "2 Nov 2026" | Run 6 |

Note: 2026-10-26 has two runs in `_runs_meta.csv` (45 and 100 questions). The core-45 filter handles this; don't double-count that date.

## 5. Per-draft notes

- **A:** y-axis is fixed at 0–1. **Do not auto-zoom:** the figure anchors at the ends claim the full scale. Five distinct figures sit at the bottom of the axis, six identical figures at the top. A dotted accent rule marks the latest value.
- **B:** the five cards are illustrative page thumbnails, not real search results; never put real site names or logos on them. The number of "new" cards = hero value rounded (1.98 → 2); the rest render as dashed duplicates tagged "≈ page 2". A distinct portrait sits above each new card and an identical figure above each duplicate.
- **C:** each grid cell needs `role="img"` and an `aria-label` with category and value; the hover `title` shows the same text. Cells are 28 px with 5 px gaps so 20 cells fit the panel.

## 6. Illustrations

- `illustrations/` holds six original SVG medallions: `aristotle.svg`, `shakespeare.svg`, `davinci.svg`, `einstein.svg`, `curie.svg`, `clone.svg` (the identical helmeted figure), plus `qr-dashboard.svg`. Each portrait is a 200×200 viewBox with a circular clip. When inlining several copies on one page, give each a **unique clipPath id** (see `fig()` in `scripts/build_final.py`).
- Regenerate them with `python3 scripts/make_assets.py <out_dir>` (needs `pip install qrcode` for the QR code).
- **Do not use Star Wars Stormtroopers**, as the client's sketch suggested, or any other franchise character: that is Disney/Lucasfilm IP on a public site. `clone.svg` is an original stand-in that does the same job.
- If the client wants real portraits instead, use public-domain images only and record the source and licence of each in the repo. Einstein's likeness is commercially licensed; check before using a photograph.

## 7. Done means

- Rebuilding against today's CSVs reproduces every value in section 4.
- Prints to exactly one A4 page; the QR code scans from the print and opens the dashboard.
- Text contrast ≥ 4.5:1 against its background; the page still makes sense with images disabled.
- Linked from the dashboard header ("One-page summary") and back.

## Package contents

```

static/                     standalone HTML of each draft + this spec (open in a browser)
previews/                   PNG renders of the above
illustrations/              the six SVG medallions + QR code
canvas-source/              the design-canvas source files (.dc.html) and canvas.json
```

`python3 scripts/compute_stats.py tracker/data/runs_top5.csv tracker/queries.txt`
